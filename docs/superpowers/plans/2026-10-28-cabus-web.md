# CABUS Web Implementation Plan

> Use superpowers:subagent-driven-development to implement and review the bounded tasks below.

**Goal:** Upgrade the approved preview into a persistent, authenticated, cloud-ready tracker and fix confirmed desktop defects.
**Architecture:** Static browser app + Worker API + D1. Local Node 24 server emulates D1 with node:sqlite so the app runs without a Cloudflare account. Store each user's validated tracker document atomically with an optimistic version to prevent lost updates. This is a deliberate simpler schema refinement of the approved design; no cross-account tracker query exists.
**Tech Stack:** HTML/CSS/JS, Workers Web Crypto, D1/SQLite, Node built-in tests, Python unittest.
**Spec:** ../specs/2026-10-28-cabus-web-design.md

## Global constraints
- Free services only; original JSON files remain untouched; use `web/` for production web files.
- No automatic upload of personal legacy files; no desktop/web automatic synchronization.
- Local preview must remain usable; only report hosting after actual deployment verification.

## Review focus
- Every data read/write/export/import is scoped to authenticated user.
- Concurrent stale saves return 409 without overwriting; failed saves preserve forms/data.
- Invalid nested records, nonfinite numbers, duplicate IDs and malformed imports are rejected.
- Recovery/change password revoke sessions; login throttling and origin checks protect auth.
- Original malformed JSON is preserved, goal calendar dates and expense months are correct.
